# Writing

Claude owns this folder. It holds the words and music that carry the game's story.

- Viktor uses what is here exactly as written. Do not reword, shorten, or extend it. If a line does not fit the game as built, say so in `docs/status.md` and leave the line as it is.
- Anything not yet written here, Viktor may draft, marked as a draft in `docs/status.md` so it can be replaced.
- Viktor writes the ambient lines himself: villagers at their day and bandits overheard, following the voices in `GAME_DESIGN.md` section 9.

| File | Contents | Status |
| --- | --- | --- |
| `melody.md` | The score of the game's one melody and its layers | First draft, to be judged by ear |
| `hesper.md` | Hesper's lines, by situation, with ids | Written |
| `stane.md` | Stane's notices, fight lines, account, and leaving | Written |

| `fragments.md` | The ten places off the path, the fisher, and Old Maren | Written |
| `households.md` | The sixteen households: who, why they left, what brings them home, what they give, their lines, and the stolen things | Written |
| `bandits.md` | Stane's men at the three places and the tax cart: names, natures, habits, overheard lines, and what they do if they stay | Written |
| `items.md` | The six unique items, the keepsakes including one per skill, and the names of materials, food, and gear | Written |
| `interface.md` | Every word the game itself shows: menus, settings, first-time prompts, notices, and what is said when the hero falls | Written |
| `companions.md` | The other five companions, every companion's perks and wish, their lines, and the pairs | Written |

Each group of lines has an id in code style, such as `hesper.arrival`. Keep those ids in the data files so a line can be traced back here.

What is left for Viktor to draft is small: shouts in a fight for ordinary bandits, greetings for villagers passing in the lane, and the companion lines for Ketch if he stands in for Tobin. Follow the voices already written.
